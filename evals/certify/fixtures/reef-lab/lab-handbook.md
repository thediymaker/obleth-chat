# Reef Lab handbook (excerpt)

Raw data lives under /data/reef-lab/raw, one folder per run named by date
(YYYY-MM-DD). Processed tables go to /data/reef-lab/processed.

Reef imagery stays embargoed for 12 months after collection; share thumbnails only
until then. Tables and protocols may be shared with collaborators at any time.

Sequencing requests go to the genomics core through its request form; allow three
weeks. Questions about the PAM fluorometer go to the lab manager, Dana Ortiz.
